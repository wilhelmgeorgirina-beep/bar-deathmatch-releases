# bar-deathmatch – Spielpakete

Hier liegen nur die fertigen Pakete des Spiels, der Quellcode bleibt
privat. Das Spiel selbst holt sich Updates von hier: es fragt beim Start
nach dem neuesten Release und laedt bei Bedarf die Datei
`bar-deathmatch.pck` nach.

    bar-deathmatch-windows.zip   Erstinstallation: entpacken, exe starten
    bar-deathmatch.pck           Spieldaten - das Update, holt sich das Spiel selbst
    bar-deathmatch.pck.sha256    Pruefsumme dazu
